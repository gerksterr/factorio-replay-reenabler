Factorio Replay Re-enabler

Two fixes for Factorio's replays. When you load a save in a newer version, the game switches replay recording off: the first tool switches it back on. The second makes a replay start later, so you don't have to sit through hours of it to reach the part you want. Saves are processed in your browser and never uploaded.

At every game update

  1. Before you load your save in the new version, open your Factorio saves folder and copy the save you last made with the previous version, for example MySave.zip. Name the copy after that version, for example MySave_2.1.23.zip. It keeps the whole replay of that version.
  2. Start the new version, load MySave, save it under the same name and quit to the menu. Only the game can convert a save to its new version, and this is also when it switches replay off.
  3. Drop MySave.zip on the tool above and save the result.
  4. Replace MySave.zip in your saves folder with the downloaded file and keep playing.

Your save keeps its name; only the copies of finished versions carry a version number. Anything you play between steps 2 and 4 isn't recorded.

Start a replay later

Load your save, choose Start replay and save when it reaches the moment the new replay should start. Drop that save and the original here. You get a copy whose replay starts at that moment and ends where the original does.

Watching it back

  • Each version's copy plays in that version of Factorio. Old versions are at factorio.com/download/archive as standalone zips that run beside the Steam version.
  • You can't move the camera freely during a replay. Save during it and load that save to look around.
  • Keep the mouse off inventory windows the replay opens. In testing, hovering over a slot made the game crash.
  • With mods, a replay only plays back with exactly the same mods and versions.

What it changes in the save

  • Switch replay back on: sets the replay switch, one byte in the map header, to on; replaces level-init.dat, the replay's starting state, with the save's current map; empties replay.dat, the recorded actions.
  • Start a replay later: takes the save with the full replay and replaces its level-init.dat with the map from the later start point and its replay.dat with the actions after that point.
  • Every other file in the zip is copied unchanged.

Tested with Factorio 2.1.23 and 2.1.24 (Space Age, no mods). Understands saves from 2.0 and 2.1 and refuses anything else. Keep a backup of saves you care about.
