Factorio Replay Re-enabler

Factorio switches replay recording off when you load a save in a newer version. This page switches it back on, with the replay starting from the save's current state. The save stays a normal Freeplay game: no scenario, no map editor, no mods.

Example
Replay switched off by update

Factorio 2.1.24 switched replay off because this map's replay was recorded in 2.1.23. Switch it back on and this file records a new replay from where it is now.

At every game update

  1. Load your latest save in the new version and immediately Save as a new name, for example mybase_2.1.24. Quit to the menu.
  2. Drop that new save on this page and save the result.
  3. Put the result in your saves folder in place of the file you dropped, and keep playing from it.

Whatever you do between loading the save in the new version and finishing these steps isn't recorded, so do them right away.

Watching it back

  • Each file holds the replay for one game version. Your older saves keep theirs: open the last save of each version in that version of Factorio and choose Start replay. Old versions are at factorio.com/download/archive (standalone zip, runs beside the Steam version).
  • Saving during a replay gives you a normal save you can keep playing from.
  • Keep the mouse off inventory windows the replay opens. In testing, hovering over a slot made the game crash.
  • With mods, a replay only plays back with exactly the same mods and versions.

What it changes in the save

  • One byte in the map header: the replay switch, set to on.
  • level-init.dat, the replay's starting state, is replaced by the save's current map state.
  • replay.dat, the recorded actions, is emptied.
  • Every other file in the zip is copied unchanged.

Tested with Factorio 2.1.23 to 2.1.24 (Space Age, no mods). Understands saves from 2.0 and 2.1 and refuses anything else. Keep a backup of saves you care about.
